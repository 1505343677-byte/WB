# WorkBuddy 技能备份

个人 WorkBuddy 技能备份仓库，用于在家通过 GitHub 网页查看与取用。

## 包含技能

| 技能 | 版本 | 说明 |
|---|---|---|
| seedance-20 | v6.7.0 | Seedance 2.0 视频提示词主技能（含 29 个子技能）。使用上游最新**发布版** v6.7.0，未含 main 分支未发布的破坏性改动。 |
| zy-cinematic-realism | v2.0.0 | 造梦师：AI 时代电影视觉指南（来自 popopo-99/zy-cinematic-realism@v2.0.0）。 |
| seedance-director | — | Seedance 2.0 导演模式，输出中英双语 JSON 分镜数组。 |
| mx-shell-prompts | — | Mx-Shell 同款影视级 Seedance 2.0 提示词优化。 |
| video-prompt-template | — | 影视级视频提示词字段化模板生成器。 |

## 目录结构

```
skills/<技能名>/SKILL.md
```

## 使用方式

将对应 `skills/<技能名>` 目录整体复制到本机 `~/.workbuddy/skills/` 即可启用。
