# 快速示例

本示例展示如何调用中文歌曲创作 Skill。实际输出会根据模型、用户补充信息和创作方向变化。

## 示例 1：完整歌曲创作

输入：

```text
请写一首关于成年人学会告别的中文歌。
要求：男声独唱，流行抒情，不要太苦情，要有城市夜晚的画面，并生成 Suno Prompt。
```

期望输出应包含：

- 创作理解
- 歌曲定位
- 副歌核心表达
- 完整歌词
- 演唱与编曲方案
- Suno Style Prompt
- 歌词自检

## 示例 2：男女对唱设计

输入：

```text
主题是分开多年后在同一座城市重逢。
请设计男女对唱方案，包括双方角色、情绪关系和副歌合唱高潮。
```

期望输出应包含：

- 演唱形式
- 角色设定
- 演唱建议
- 歌词分配方案

## 示例 3：歌词审核

输入：

```text
请从文学性、情绪、演唱性、原创性和传播性审核下面这段歌词，并给出优化版本。
```

期望输出应包含：

- 评分
- 问题
- 修改建议
- 优化版本

## 示例 4：Suno Prompt 生成

输入：

```text
根据这首歌的定位和歌词，生成适合 Suno 的英文 Style Prompt、Negative Prompt 和中文制作说明。
```

期望输出应包含：

- English Style Prompt
- Negative Prompt
- 中文制作说明

## 发布前建议

- 如果用于公开项目，建议在 README 中补充许可证信息。
- 如果用于团队工作流，建议把常用品牌、主题或禁用表达补充到 `knowledge/`。
- 如果用于 Suno 批量生成，建议每首歌都保留歌名、歌词版本和 Prompt 版本，便于回溯。
