# 中文歌词韵脚库

本文件提供常用中文歌词韵脚参考。创作时应优先保证语义自然和情绪准确，韵脚只作为辅助。

## 使用原则

- 优先使用宽韵，避免强行押死韵。
- 副歌可使用更集中韵脚，增强记忆点。
- 主歌可弱押或隔句押韵，让叙事更自然。
- 不要为了押韵堆叠空泛词。

## a / ia / ua 韵

适合：开阔、明亮、青春、告白、释怀。

常用字词：

- 啊、吧、吗、呀
- 花、家、沙、霞
- 他、她、它
- 话、画、牵挂、放下
- 回答、抵达、长大

示例方向：

- “把没说完的话，留给风回答”
- “后来我才长大，也学会放下”

## ai / uai 韵

适合：爱情、等待、遗憾、城市感。

常用字词：

- 爱、来、开、白、海
- 等待、离开、回来、盛开
- 现在、未来、后来
- 依赖、释怀、尘埃

示例方向：

- “我还在原地等一场花开”
- “你离开以后，雨落成尘埃”

## an / ian / uan / üan 韵

适合：温柔、怀念、叙事、电影感。

常用字词：

- 晚、慢、散、岸
- 时间、从前、明天、再见
- 圆满、遗憾、答案
- 转弯、靠岸、习惯

示例方向：

- “把遗憾写进那年的夏天”
- “我们在转弯处学会再见”

## ang / iang / uang 韵

适合：大气、主题歌、成长、力量感。

常用字词：

- 光、浪、往、望
- 方向、远方、肩膀、回响
- 生长、倔强、滚烫
- 月光、海浪、空旷

示例方向：

- “把沉默唱成回响”
- “我沿着风，走向有光的地方”

## ao / iao 韵

适合：青春、奔跑、遗憾、轻快或抒情。

常用字词：

- 笑、叫、跑、找
- 拥抱、骄傲、打扰
- 街角、心跳、刚好
- 迟到、年少、喧闹

示例方向：

- “你在街角笑，我假装刚好”
- “那些年少，终于被风吹到”

## ei / ui 韵

适合：细腻、低回、孤独、冷感。

常用字词：

- 泪、杯、灰、归
- 以为、后悔、安慰
- 玫瑰、结尾、余味
- 退回、奉陪、疲惫

示例方向：

- “我把沉默倒进空杯”
- “你留给我的，只剩一点余味”

## en / in / un 韵

适合：克制、深情、内心独白。

常用字词：

- 人、门、痕、真
- 认真、转身、黄昏
- 体温、亲吻、掌纹
- 等一等、问一问

示例方向：

- “黄昏关上门，也关不住我们”
- “你的掌纹，还留着旧体温”

## eng / ing / ong 韵

适合：城市、命运感、成熟抒情、OST。

常用字词：

- 风、梦、灯、等
- 心动、落空、相逢
- 途中、夜空、普通
- 清醒、安静、约定

示例方向：

- “城市的灯，替我等过一阵风”
- “我们在途中，错过同一个梦”

## i / ü 韵

适合：轻盈、私密、细腻、独白。

常用字词：

- 你、雨、句、去
- 秘密、距离、回忆
- 四季、消息、可惜
- 继续、失去、相遇

示例方向：

- “我把回忆折进雨里”
- “最远的距离，是还想见你”

## ou / iu 韵

适合：温柔、叙事、留白、告别。

常用字词：

- 走、旧、久、留
- 以后、路口、左右
- 温柔、等候、回头
- 自由、保留、拥有

示例方向：

- “我在路口，学会不回头”
- “把你的温柔，还给很久以后”

## 常见副歌韵脚选择

- 爱情遗憾：ai、an、ou
- 青春回忆：ao、ai、ian
- 治愈陪伴：ou、en、ing
- 大气主题：ang、ong、eng
- 城市孤独：ei、eng、in
- 国风抒情：an、ang、ing

## 避免高频空泛尾词

谨慎使用以下词，除非有具体语境和新鲜表达：

- 远方
- 光芒
- 梦想
- 翅膀
- 天堂
- 海洋
- 方向
- 坚强
- 飞翔
- 绽放
