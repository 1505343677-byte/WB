# 视频提示词完整写作规范

## 总体结构

```
风格与氛围 → [Acting（含人物时）] → Reference（有参考图时） →
叙事概要 → [台词（含台词时）] → 动态描述 → 静态描述 → 避免列表
```

---

## 一、风格与氛围

**合并 Style + Lighting + Color + Camera 为一个丰富段落。** 用流畅的散文体，不用标签分裂。

### 必须包含的元素

| 元素 | 要求 | 示例 |
|------|------|------|
| 时间/地域/天气 | 具体到可以想象 | "非洲草原金色黎明""霓虹浸染的赛博朋克都市" |
| 光线 | 色温+方向+质感 | "温暖琥珀色晨光横掠草原""低角度侧逆光" |
| 主色调 | 颜色必须绑定载体 | "深青蓝天幕""深靛蓝夜空饱和着洋红与青色招牌辉光" |
| 氛围物质 | 空气/雾/尘/雨等 | "体积感尘埃雾气""湿润反光表面" |
| 摄影风格 | 风格化+技术特征 | "电影感、末日级尺度""金属冷光质感、凌厉动感" |
| 排除声明 | 非XX | "非3D渲染，非游戏引擎画面" |

### 写作要点

- 写成一个自然段，不用分号拆散
- 先写大环境，再写光线，再写色彩与表面反应，最后写摄影风格
- 每个名词都带修饰语：不只写"云层"，写"低伏云层"；不只写"地面"，写"湿滑沥青路面"

### 样例对照

**差：**
```
风格：非洲草原 黎明 光线 电影感
```

**好：**
```
风格与氛围：非洲草原金色黎明，温暖琥珀色晨光横掠草原，
深青蓝天幕缀以低伏云层，蝗群扬起的体积感尘埃雾气。
万千蝗虫翅膀反光闪烁，身体运动模糊。电影感、末日级尺度、
具象的群集行为质感。
```

## 二、叙事概要

**一句话**，不是事件描述，而是"这个视频的画面叙事弧线"。写法：从开头状态 → 中间转折/高潮 → 结尾状态。

### 要素

- 包含关键的镜头类型转换（"切至""一镜到底""切入升格"）
- 包含主要视觉事件（"如潮水般涌入""推进器点燃减速""砸中路面"）
- 不写无关背景信息

### 样例

```
叙事概要：猴面包树草原黎明时分，蝗群如潮水般自镜头后方涌入画面，
整片蝗虫背对镜头。切至一镜到底镜头，镜头向蝗群前推，万千蝗虫
如潮水般向镜头扑来并将镜头后方吞没；其中一只蝗虫飞向镜头时
切入升格，镜头跟随其后摇并锁定，清晰捕捉其翅膀振动三至四次；
遮天蔽日的蝗群继续向前飞去。
```

```
叙事概要：一道身影从赛博都市摩天楼坠落，下落过程中机甲附体变身，
最终以霸气姿态落地。
```

## 三、动态描述

用 **"段"** 分段，段首加标识："第一段镜头——""切至第二段镜头——""切至特写锁定机位——"。

### 每段内融合的元素

把以下全部写进散文体中，不要要素清单：

1. **画面内容**：看到了什么
2. **摄影机**：焦段 + 运动 + 视角高度
3. **光影变化**：光线如何与画面内容互动
4. **感官细节**：粒子、反光、振翅、冲击波、水花、烟雾
5. **材质与运动方式**：翅膀模糊/透明翼膜闪烁/冲击波震裂地面
6. **转场方式**：硬切 / 切至 / 切入升格 / 匹配剪辑
7. **节奏变化**：正常速 → 升格 → 锁定静止 → 恢复

### 写作要点

- 不用"Shot N（0-5s）"，用"第一段镜头——"开头
- 摄影机运动写在画面内容之前："广角缓速后拉，草原沐浴在朝阳中"
- 每个名词写出材质和动态状态："透明翼膜在晨光中闪烁""金属甲片从四面八方飞来"
- 升格/变速明确标注："画面切入升格，镜头平滑后摇跟随"
- 空间关系明确："由画面下、左、右、上边缘如涨潮般涌入"
- 结束要有画面收束："遮天蔽日，直至画面只剩振翅与尘埃"

### 样例

```
动态描述：
第一段镜头——广角缓速后拉，黎明时分猴面包树散布的广袤草原
（参考图2）沐浴在琥珀色朝阳中，地面低伏尘埃薄雾。蝗群
（参考图1）自镜头后方涌入画面，整片蝗虫背对镜头，由画面
下、左、右、上边缘如涨潮般涌入，数千计鼓翅在暖光中闪烁，
蝗群令空气愈发稠密。

切至第二段镜头——一镜到底，中景广角前推——镜头向遮天蔽日般
黑压压飞来的万千蝗群推进，蝗群塞满整个画面，个体穿越焦平面，
翅膀模糊。当其中一只蝗虫飞向镜头时，画面切入升格，镜头平滑
后摇跟随该蝗虫轨迹，随后锁定静止——蝗虫翅膀清晰振动三至四次，
透明翼膜在晨光中闪烁，复眼与锯齿后腿细节可见。镜头锁定静止，
万千蝗群继续倾泻而过，飞越镜头后方，遮天蔽日，直至画面只剩
振翅与尘埃。
```

### 含人物时的动态描述要点

- 动作要具体："金属甲片从四面八方飞来，依次扣合在双臂与躯干上"
- 效果要可视："接缝处蓝色能量脉络逐一亮起""连接点迸射火花"
- 空间位置重新锚定："双足砸中湿滑沥青路面，冲击波震裂地面、掀飞积水"
- 情绪通过身体状态表达："从蹲姿挺起成蓄势站姿，一拳撑地"

## 四、静态描述

独立章节，不放在动态描述里。极度细描，分两部分。

### 4.1 场景细描

- 地形：类型、起伏、延伸到何处
- 植被/建筑：每一样写材质和形状
- 天气与光线在场景表面的呈现
- 特殊物质：尘埃薄雾/水洼/全息广告/霓虹

**样例：**
```
静态描述：非洲草原黎明，散布猴面包树，粗壮纺锤形树干与
伞状细叶树冠，干燥金色草甸延伸至远处低山。温暖琥珀色朝阳
自右侧横掠，深青蓝天幕低伏云带。地面尘埃薄雾。
```

### 4.2 物体/生物/人物细描

**生物细描要素：**
- 体形：大小、比例、姿态
- 体色与纹理：斑驳/光滑/粗糙、颜色分布
- 关键器官：复眼、触角、口器
- 运动结构：翅膀（膜质/脉纹/透明）、足（锯齿/钩爪/发达跳跃足）
- 附加特征：触角长度、甲壳厚度感

**样例：**
```
蝗虫：粗壮棕褐色蚱蜢体，斑驳甲壳，大型复眼，锯齿状后腿股节，
半透明脉纹双翅，长触角，发达跳跃足。
```

**道具细描要素：**
- 整体材质：金属/塑料/木
- 颜色分布
- 结构部件逐件描述
- 表面处理：抛光/磨砂/氧化/污渍

**人物细描要素：**
- 服装逐件：从外到内、从材质到颜色到款式
- 发型发色
- 体型姿态
- 配饰与装备
- 皮肤/面部特征（不涉及年龄标记）

**样例：**
```
身影的机甲：流线型深色金属甲片，接缝处青色能量脉络发光，
背部推进器，全封闭面罩头盔。
```

## 五、避免列表

顿号连接，按维度排列：

| 维度 | 示例项 |
|------|--------|
| 视觉 | CG动画感、3D渲染感、场景漂移、出现人物/动物、颜色偏移 |
| 空间 | 运动轨迹整齐、形成阵列、个体间距一致 |
| 音频 | 出现旁白、出现背景音乐、音效缺失 |
| 表演（含人物时） | 表情夸张、动作不自然、台词腔调不对 |
| 连续性 | 道具消失、服装变化、光线跳变 |
