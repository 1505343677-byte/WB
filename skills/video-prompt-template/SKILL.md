# 视频提示词模板生成器

## 设计理念

**用第一版的分字段结构做骨头，用样例的画面丰富度做肉。**

- 字段分拆保持清晰——每个字段负责一类信息，AI 引擎不需要从混合段落里猜每一层的意思
- 每个字段内部用**流畅自然段**书写——不只列要素，要写出光线如何与表面互动、色彩如何附着在具体物体上、空间关系如何逐层展开
- 分镜用 Shot N（时间区间）的格式，但每个 Shot 内部写成像样例那样有节奏、有气氛、有材质细节的段落

## 输出结构

```
风格前缀（字段式）→ 叙事概要 → [台词] → 逐镜分镜 → 静态描述 → 避免列表
```

## 第一部分：风格前缀（字段式）

按以下顺序逐个字段书写，每个字段用 `字段名：` 开头。字段内部写自然段落，不写要点列表。

```
Style → Reference → 空间设定 → Lighting → Color → Camera → Acting → Continuity → Audio
```

### 各字段写作要求

#### Style
技术规格 + 画面质感 + 具体设定 + 排除声明。写一个完整自然句。
```
Style: 8K IMAX，photorealistic，真实电影纪录片质感，非洲马达加斯加猴面包树草原金色黄昏，
末日蝗灾过境，非 CG 动画，非 3D 渲染，非游戏引擎画面。
```

#### Reference
视觉参考描述 + 图像占位符。有图时写，无图时省略。**不只写"参考图 X"，要把图中关键视觉特征逐项写出，让即使没有图也能想象。**
```
Reference: 场景色调与地貌严格参考猴面包树荒漠黄昏景观 {{Mixed 1}}：
粗壮纺锤形猴面包树散落在干燥金色草甸上，远处有朦胧山脉剪影，低角度夕阳从右侧横掠，天空厚重积云边缘被染成暖金与淡橙色。
```

#### 空间设定
人物/物体在空间中的位置、朝向、距离、与摄影机/观众的关系。**写出空间层次**：近景有什么、中景有什么、远景有什么。
```
空间设定：摄影机位于荒漠地面以上约 1.5 米处，面向开阔平原。
近景有干枯低矮灌木，中景散落两棵猴面包树，远景地平线上有更多猴面包树剪影和朦胧山脉。
画面初始空旷寂静，随后蝗虫从画面后方与画外四面八方涌入。
```

#### Lighting
色温 + 光源方向 + 光线与场景表面的互动 + 暗部层次。**写出光的质感**：是硬是软、有霾有尘、光束形状。
```
Lighting: 日落前黄金时段，低角度侧逆光从画面右后方斜斜射入，色温约 3200K 偏暖。
光线穿透稀薄尘埃雾在空气中形成可见的光束通道，
猴面包树在龟裂地面上拖出细长暗影，暗部保留赤褐色层次，不压死。
```

#### Color
色彩元素逐一列举，**每个颜色绑定具体载体**，最后总结整体色调风格与质感。
```
Color: 龟裂赤褐色土地、枯黄与金棕色短草、猴面包树暖灰褐色树皮、深青蓝渐变天空、
云层边缘染暖金与淡橙、棕褐色蝗虫群剪影、浅黄褐色扬尘。
整体色调克制偏纪录片风格，带轻微胶片颗粒与尘埃光晕。
```

#### Camera
摄影设备 + 镜头特性 + 物理参数 + 画面质感。**不只写参数，写出参数带来的视觉结果。**
```
Camera: 使用 IMAX 胶片摄影机/ARRI 纪录片风格，24mm–50mm 广角变焦范围，
真实物理景深让远景山脉轻微虚化，180° shutter motion blur 令快速物体产生自然的拖尾模糊，
自然手持带来微弱的呼吸感晃动，暗部有细节，高光不过曝。
```

#### Acting
含人物时必填，无人物时删除。**每个角色单独写，情绪用行为描述代替形容词。**
```
Acting: 专业越剧正式演出表演，白娘子身段稳，声音有中气、有厚度、有压场感，
情绪不是柔弱，而是悲情里带着不服输；法海冷峻、克制、压迫感强，念白稳、沉、准。
两人都使用越剧念白方式，带中州韵和吴语味，字头不要硬，尾音有戏曲韵味，不要普通话话剧腔。
```

#### Continuity
**所有必须在全片保持一致的元素逐一列出**，防止身份漂移。
```
Continuity: 猴面包树种类与分布、黄昏光线方向与色温、尘土色调与浓度、
蝗虫体型与颜色、纪录片手持质感、Scene 地貌特征在整个视频中保持一致，不发生场景漂移。
```

#### Audio
按时间线描述音频状态变化 + 排除声明。**写出每段时间的声音事件，不是一句话概括。**
```
Audio: 无旁白，无背景音乐，无配乐。
0-4s：干燥草丛被气流与虫翅扰动的沙沙声、极远处低频虫群振翅嗡鸣；
4-10s：沙尘颗粒撞击镜头或擦过麦克风的轻微噪声、虫群震耳嗡鸣逐渐逼近；
10-12s：嗡鸣达到顶点后被尘雾闷住变低沉。无字幕，无旁白。
```

## 第二部分：叙事概要

一句话，概括整个视频的画面叙事弧线。**从视觉角度写，不是事件概述。**包含关键镜头转换和主要视觉事件。

```
叙事概要：猴面包树草原黄昏时分，一只蝗虫从镜头右下掠过，随后虫群自镜头后方
各处随机涌入画面并涌向远方。切至同一片草原另一处，镜头面向虫群缓慢前推，
万千蝗虫以极快速度掠过镜头，扬起的尘埃沾染在镜头上。
```

## 第三部分：逐镜分镜

使用 `Shot N（时间区间）` 的格式。每个 Shot 内部写成一个**流畅的自然段**：

**必须融合的元素：**
- **画面内容**：看到了什么，光线如何落在上面
- **摄影机运动与参数**：焦段、光圈、运动方式，写在画面内容之前
- **空间位置与朝向**：谁/什么在画面哪里，朝向哪里，背景是什么
- **物体/人物的运动与状态**：怎么动的，轨迹如何，有什么视觉特征
- **材质与光影互动**：翅膀的反光、地面的龟裂纹理、尘埃的透光感
- **该镜专属音频指令**：这一段时间内声音的状态

**写作要点：**
- 不只写"中景，摄影机后拉"，写"广角极缓后拉，黄昏中的猴面包树草原铺展在画面中央"
- 不只写"蝗虫飞过"，写"一只棕褐色蝗虫从画右下方高速飞入，翅膀因运动模糊呈半透明残影"
- 不只写"虫群来了"，写"画面左下角先零星闪过几道模糊的棕色拖影，紧接着右下方也出现但时间错开半秒，三三两两、毫无规律地从画面各处冒出"——**群体行为描写必须避免对称、同时、均匀的语言**
- 镜间跳转标注："切至""硬切至""切入升格"
- 结尾要有画面收束感

**⚠ 群体/集群行为描写规则（虫群/鸟群/人群/碎片等）：**
- **禁止**使用"四个边缘同时涌入""左右上下同时""整齐推进""如涨潮般""成排飞来"等对称、均匀、有方向性的语言——会让 AI 模型生成阵列/网格化的不自然群体
- **必须**使用错时、错位、随机密疏分布的描述："先从左下零星出现，半秒后右下跟上""有的区域密到遮蔽背景，有的区域突然稀疏露出天空""内部充满逆向、横向、斜插的个体轨迹，没有统一朝向"
- **比喻选择**：用"被风搅动的沙暴"而非"涨潮"——前者暗示无序，后者暗示均匀推进
- **运动模糊**：对高速群体必须强调"所有个体均带有强烈运动模糊，近处只剩速度残影"——既增加真实感，又降低模型算力负担（模型不需要渲染每只个体的细节）

**示例：**
```
Shot 1（0-5s）
广角极缓后拉，IMAX 35mm，T4.0。黄昏中的猴面包树草原铺展在画面中央，
最近一棵粗壮灰褐色猴面包树占据中景偏左，远处两到三棵猴面包树散落在金色地平线上，
地面干枯龟裂、杂草低矮。0-1s 时，一只棕褐色蝗虫从画右下方高速飞入，
翅膀因运动模糊呈半透明残影，斜穿过镜头前景向画面中远处飞去。
约 2.5s 时，画面左下角先零星闪过几道模糊的棕色拖影，紧接着右下方也出现但时间错开半秒，
数量更密——虫影三三两两、毫无规律地从画面各处冒出，有的贴地低飞，有的从树冠背后弹射而出。
零散个体出现后约一秒，虫群密度骤然上升，但不是均匀推进——有的区域密到遮蔽背景，
有的区域突然稀疏露出天空，密疏分布完全随机。虫群整体向远方流动但内部充满逆向、横向、
斜插的个体轨迹，没有统一朝向。所有蝗虫均带强烈运动模糊，近处只剩速度残影。

切至 Shot 2（5-10s）
同时间同地域同色调，不同场景——更低矮干燥的草甸。手持摄影机，
50mm 标准焦段，T2.8，镜头面向远方缓慢前推。万千蝗虫从远处涌来，密疏不均、速度不一、
高度随机，像一场突然加速的褐色沙暴。蝗虫以极快速度掠过镜头两侧和上方，
所有个体带强烈运动模糊，近处只剩深棕色与黑色相间的抽象速度残影。
虫群扬起的干燥尘土落在镜头表面，形成局部半透明污迹和不规则颗粒遮挡。
```

## 第四部分：静态描述

独立章节，不嵌入分镜。**极度细描场景中的一切。** 分两块：

### 场景细描
地形、植被、建筑、天气、光线在表面的呈现方式。**每样东西写材质和形状**。
```
猴面包树：粗壮纺锤形灰褐色树干向上收窄，顶端展开伞状细叶树冠，树皮呈纵向裂纹纹理。
地面：干燥龟裂的红褐色土壤，覆盖枯黄与金褐色短草，点缀低矮干枯灌木与碎石。
远景：远处地平线上朦胧蓝灰色山脉剪影。
```

### 物体/生物/人物细描
**生物**：体形、甲壳纹理、复眼、触角、翅脉、关节、足的形态
**道具**：材质、颜色、结构部件、表面光泽与磨损
**人物**：服装逐件描述、发型发色、身形姿态、配饰装备

```
蝗虫：中等体型棕褐色蚱蜢状昆虫，身体修长，背部有斑驳深褐与浅褐相间甲壳，
大型黑色复眼，细长丝状触角，发达锯齿状后腿股节，两对半透明带深褐色脉纹的翅膀，
飞行时翅膀高速振动呈模糊状态。
```

## 模板变体

### 变体 A：无人物表演（空镜/风景/物件/环境）
- 删除 Acting 字段
- 空间设定 改为描述环境的构图和层次
- Audio 无台词指令，只保留环境声/SFX
- 分镜中不写人物位置/朝向/表演/情绪
- 静态描述只有场景和物体/生物细描
- 避免列表删除人物相关项

### 变体 B：无台词（默片式表演/纯动作/情绪段落）
- 全部字段保留
- Acting 强化肢体语言和微表情
- 台词段落省略
- 分镜中不写台词，强化身体语言/眼神/呼吸/手势
- Audio 只保留环境声/SFX
- 避免列表删除台词相关项

## 写作检查清单

生成提示词后自查：
1. 每个字段是否写了自然段落而非要点列表？
2. 每个颜色是否绑定到了具体载体上？
3. Lighting 是否写了光线与场景的互动方式？
4. 分镜是否融合了画面内容 + 摄影机 + 材质细节，而非拆开的清单？
5. 静态描述是否极度细致——每样东西有材质和形状？
6. 避免列表是否覆盖全部五个维度？
7. 是否有排除声明（非CG/非3D/非XX）？
