# Patterns & Techniques

## 觸發事件設計公式

**When to use**: 構思故事開場時
**How**: 問自己兩個互為鏡像的問題 —
1. 我的主角可能遇到的最糟的事是什麼？如何讓它轉化為最好的事？（悲→喜）
2. 我的主角可能遇到的最好的事是什麼？如何讓它轉化為最糟的事？（喜→悲）

案例：《克拉瑪對克拉瑪》— 最糟：妻子離開 / 最好：發現自己可以成為充滿愛的人

## 場景設計檢查清單

**When to use**: 每個場景寫完後或修改時
**How**: 逐一檢查五要素 —
1. **轉捩點**: 結尾的價值狀態與開頭不同嗎？（正→負 或 負→正）
2. **節拍**: 場景內角色的行為是否經歷了細微的變化？
3. **鋪陳/回饋**: 是否植入了後續可發酵的細節？
4. **情緒動態**: 情緒在場景中是上升還是下降？
5. **壓力下的選擇**: 角色是否被迫作出了有意義的選擇？

## 兩難困境設計

**When to use**: 角色需要展示真正性格的時刻
**How**: 設計一個「善 vs 善」或「惡 vs 惡」的選擇 —
- 角色必須在兩個不可兼得的價值之間抉擇
- 兩個選項都有代價（否則不是真正的選擇）
- 案例：超人 → 救紐澤西還是救加州？遵父命還是救愛人？

## 對立力量四層次檢核

**When to use**: 故事平淡、張力不足時
**How**: 檢查對立力量是否在四個層次上都存在 —
1. **內在衝突**: 主角和自己過不去（恐懼、罪惡感、自卑）
2. **個人衝突**: 家人、朋友、愛人、對手
3. **社會衝突**: 體制、法律、階級、文化規範
4. **環境衝突**: 自然、災難、時間、空間限制

層次疊加愈多，故事張力愈強。

## 懸念 vs 驚喜

**When to use**: 決定隱藏還是揭露資訊時
**How**:
- **懸念 (Suspense)**: 讓觀眾知道炸彈在桌下，角色不知道 → 觀眾全程緊張
- **驚喜 (Surprise)**: 觀眾和角色同時發現炸彈 → 瞬間衝擊但缺乏持續張力
- 麥基主張：鋪陳 → 讓觀眾知道部分資訊 → 懸念 → 更持久的戲劇張力

## 從內向外寫作法

**When to use**: 開始寫一個新場景時
**How**:
1. 進入角色的主觀視角，想像自己就是他
2. 問：此時此刻，這個角色想要什麼？他認為怎麼做可以得到？
3. 寫下他的行動 → 世界如何回應？回應是否符合期望？
4. 如果出現鴻溝，角色的下一個行動是什麼？
5. 重複直到場景的轉捩點自然浮現

## 開場的極簡原則

**When to use**: 修改開場場景時
**How**: 以柏格曼為標竿 —
- 列出你認為觀眾「必須知道」的十件事
- 刪掉其中七件
- 剩下的三件，用角色的行動來傳達，不用解說性的對白或旁白
- 問：「觀眾能不能從角色的行為中自行推斷？」

## 高潮檢查法

**When to use**: 規劃或修改結局時
**How**:
1. 高潮是否不可逆？（不能是「其實是一場夢」）
2. 高潮是否由主角自己的選擇和行動導致？（不能是巧合或他人解救）
3. 高潮是否釋放了故事累積的所有力量？
4. 結局後是否有足夠的緩衝讓觀眾喘口氣？
