# Part 2: 故事設計的原則

## Core Idea

故事的核心是「本質」— 就像原子中旋轉的能量，無形卻有生命。麥基在本部中系統性地拆解故事的元素：從結構光譜的三種形式（大情節/小情節/反情節），到背景設定如何約束故事的可能性，再到類型慣用手法如何成為作者的工具而非枷鎖，最終歸結於角色與意義的深層關係。

## Frameworks Introduced

- **結構光譜 (The Structure Spectrum)**
  - 大情節/原型情節 (Archplot)：經典設計 — 因果清晰、封閉式結局、單一主動主角、線性時間、連貫一致的世界
  - 小情節 (Miniplot)：簡約設計 — 開放式結局、內在衝突、多重/被動主角、巧合驅動
  - 反情節 (Antiplot)：反結構 — 巧合取代因果、非線性時間、破碎現實、荒誕邏輯
  - When to use: 幾乎所有商業短劇/電影都應選大情節；小情節適合文藝/獨立製作；反情節僅在有意打破常規時使用

- **背景設定四維度 (Four Dimensions of Setting)**
  - 時代（何時）、期限（多長）、地點（哪裡）、衝突層面（什麼層次）
  - 背景設定愈具體，故事的普遍性反而愈高 — 這是一個重要的悖論
  - When to use: 創建新項目時，先鎖定這四個維度再開始寫作

- **類型慣用手法 (Genre Conventions)**
  - 每位編劇的第一項功課是定義自己的類型，然後研究決定此種類型的慣用手法
  - 精通經典形式是走向前衛的必經之路：先把原型劇情寫好，再談實驗
  - When to use: 決定短劇類型後，列出該類型觀眾期待的慣用手法，確保不遺漏但也巧妙顛覆部分期待

- **主角的定義 (The Protagonist)**
  - 主角可以是單一角色、複數主角（共同希望、共同承擔）或多重主角（各自獨立的故事線）
  - 複數主角條件：群體中每個人都懷抱相同的希望，相互扶持，同甘共苦
  - 主角必須具備意志力 + 能力 + 讓觀眾產生同理心的特質

- **角色 vs 人物塑造 (Character vs Characterization)**
  - 人物塑造：角色的年齡、外貌、職業、舉止等外在特徵
  - 真正角色：壓力下作出的選擇所揭示的內在本質
  - When to use: 檢查角色是否立體 → 問「他在巨大壓力下會怎麼選？」

## Key Concepts

- **故事本質**：無形但有生命的存在，語言只是媒介，不是故事本身
- **自覺欲望 vs 不自覺欲望**：角色表面追求的目標 vs 內心深處真正需要的東西
- **主角意志力**：主角的欲望驅動力必須足夠強大，能推動故事直到終點
- **同理心**：觀眾不需要喜歡主角，但必須能理解主角，願意跟隨他的旅程

## Anti-patterns

- **訊息過載的開場**：第一幕塞入太多背景說明 — 觀眾不需要知道一切才開始關心
- **主角動力不足**：被動的主角讓故事癱瘓 — 主角必須有足夠的意志力推動故事
- **類型混亂**：混合多種類型但未掌握任何一種的核心慣用手法

## Key Takeaways

1. 先掌握經典大情節，再考慮實驗其他結構形式
2. 背景設定愈具體，故事愈能跨文化傳播 — 這是麥基最重要的悖論之一
3. 角色真相只能通過壓力下的選擇揭示，不能靠對話「說出來」
4. 定義類型 → 掌握慣用手法 → 在此基礎上創新
5. 自覺欲望驅動情節，不自覺欲望賦予深度 — 兩者缺一不可
6. 複數主角必須「同希望、共命運」
