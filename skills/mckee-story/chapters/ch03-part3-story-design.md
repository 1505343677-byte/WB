# Part 3: 故事設計的原理

## Core Idea

這是全書最實戰的部分。麥基逐層拆解故事設計的每一個結構單元：從觸發事件如何啟動故事引擎，到幕的設計如何分配張力，到場景如何透過節拍和轉捩點推進，再到危機、高潮與結局的精確設計。核心引擎是「鴻溝原理」：角色行動 → 期望落空 → 鴻溝出現 → 角色調整 → 故事推進。

## Frameworks Introduced

- **觸發事件 (The Inciting Incident)**
  - 必須徹底顛覆主角生活中的平衡力量
  - 喚起主角的自覺欲望，也可能激發不自覺的欲望
  - 在觀眾腦海中提出「劇情重要疑問」（這部電影到最後會怎樣？）
  - 時機：觀眾對角色了解夠多、夠深，足以作出完整回應的那一刻
  - 設計練習：我的主角可能遇到的最糟的事是什麼？如何讓它轉化為最好的事？

- **幕的設計 (Act Design)**
  - 第一幕 ≈ 25% 片長，第一幕高潮出現在 20-30 分鐘處（120 分鐘電影）
  - 最後一幕最短（≈20 分鐘），提供瞬間加速感直抵高潮
  - 每一幕的高潮都是不可逆的價值轉折
  - 幕與幕之間的情緒節奏應有起伏變化

- **場景設計 (Scene Design)** — 每個場景的要素
  - 轉捩點 (Turning Point)：價值從正到負或從負到正
  - 鋪陳/回饋 (Setup/Payoff)：資訊遞送的時機決定驚喜還是懸念
  - 情緒動態：場景中的情緒如何流入和流出
  - 節拍 (Beat)：角色行為的最小單位，節拍的累積形塑場景
  - 壓力下的選擇：場景的真正目的是迫使角色作出選擇

- **鴻溝原理 (The Gap)**
  - 角色採取行動 → 期望世界作出某種反應 → 世界回應了截然不同的東西
  - 這個落差 = 鴻溝 = 故事推進的動力
  - 當鴻溝出現，角色必須調整策略，展開新的行動

- **危機、高潮、結局 (Crisis, Climax, Resolution)**
  - 危機：兩難選擇（主角必須在兩個不可兼得的選項中抉擇）
  - 高潮：不可逆的價值轉折，故事所有力量的終極釋放
  - 結局緩衝：高潮後給觀眾喘息的空間（布幕緩緩降下）

- **少即是多 (Less is More)**
  - 以柏格曼為例：只給觀眾最少的必要資訊，觀眾的集體潛意識會補完其餘
  - 觸發事件的通病：延遲中心劇情，塞入過多背景說明
  - 解決方法：問自己「觀眾真的需要知道這個嗎？」

## Key Concepts

- **事件**：亨利·詹姆斯 — 事件可以是微小的事，如「一個女人把手放在桌子上，帶著某種神情看著你」。時機適合，即使只是一個動作，也能傳達舊生活的崩塌或新生活的開始。
- **劇情重要疑問**：觸發事件後，觀眾心中自動浮現的中心問題（他們會在一起嗎？他會成功嗎？）
- **必要場景**：觀眾基於類型和劇情發展而預期出現的場景
- **節拍**：角色行為變化 → 場景的內在生命來自節拍的累積

## Anti-patterns

- **延遲觸發事件**：開場花太多篇幅鋪陳背景，讓觀眾不耐煩
- **空有轉折無鋪陳**：突然的轉折沒有前面的鋪陳支撐，成為「機械降神」
- **最後一幕拖太長**：高潮後的情節如果延展過長，觀眾情緒會消散
- **主角被動**：主角一直在「反應」而非「行動」，故事缺乏推進力

## Key Takeaways

1. 觸發事件是整部劇本「改寫次數最多的場景」— 值得反覆打磨
2. 「最糟 → 最好」和「最好 → 最糟」是設計觸發事件的兩個核心提問
3. 每一幕高潮都必須是不可逆的價值轉折
4. 場景的靈魂不在對白，在於節拍累積而成的轉捩點
5. 鴻溝是故事的心跳 — 沒有落差就沒有故事
6. 柏格曼的極致簡約：幾乎什麼都不說，卻什麼都傳達了
