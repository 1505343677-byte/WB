# Part 4: 編劇實戰篇

## Core Idea

這是麥基從理論走向實戰的最後一步。本部涵蓋了故事設計最重要的準則 — 對立原則、鋪陳與回饋的精確技巧、問題診斷與解決方案、角色塑造的實戰方法、文本寫作要點，以及完整的寫作方法論。

## Frameworks Introduced

- **對立原則 (The Principle of Antagonism)**
  - 麥基稱之為「故事設計最重要的準則，但很少人真正了解」
  - 定義：主角和主角的故事只有在對立力量迫使下，才能在理智面引人入勝、在感情面扣人心弦
  - 對立力量 ≠ 反派，而是「對抗主角意志及欲望的所有力量之總和」
  - 人性的保守本質：我們絕不做不必要的事 — 所以對立力量必須足夠強大才能推動故事
  - 對立四層次：內在衝突（自我）、個人衝突（家庭/朋友）、社會衝突（體制）、環境衝突（自然/命運）

- **鋪陳與回饋 (Setup and Payoff)**
  - 鋪陳：在觀眾不知情的情況下植入資訊
  - 回饋：當鋪陳的資訊以出乎意料的方式返回時，觀眾恍然大悟
  - 兩種模式：懸念（觀眾知道炸彈在桌下）vs 驚喜（觀眾和角色同時發現）
  - 鋪陳必須足夠隱蔽，回饋必須足夠有力

- **角色塑造實戰**
  - 角色不是「說明」出來的，是「選擇」出來的
  - 壓力愈大，選擇愈能揭示真實性格
  - 為角色設計「兩難困境」— 在兩個不可兼得的價值之間抉擇
  - 超人案例分析：普佐讓超人同時面臨兩個無法兼顧的選擇 → 救哪裡？孝vs愛？

- **文本寫作要點**
  - 對白不是日常對話，而是精煉後的行動語言
  - 每個角色說話的方式應反映其社會背景、教育程度、性格特質
  - 潛文本 (Subtext)：角色說的話 vs 角色真正的意思 — 差距愈大，張力愈強

- **寫作方法論 (A Writer's Method)**
  - 從內向外寫：進入角色的內心世界，透過他的雙眼觀看
  - 先大綱後細節：先確定結構骨架（幕、場景、轉捩點），再填細節
  - 寫作-分析-改寫循環：一面寫一面讀，一面創作一面批評
  - 知識從左腦轉換到右腦：先智性地理解原理，反覆練習直到變成直覺

## Key Concepts

- **負面價值**：花心思營造故事的負面，讓對立力量更強大，角色就更完整
- **衝突解除場景**：高潮後給觀眾喘息的緩衝 — 電影需要「布幕緩緩降下」
- **障礙設計**：主角的每一步都應遇到新的、更大的障礙，讓故事不斷升溫

## Anti-patterns

- **對立力量太弱**：主角太強、對手太弱 = 平淡乏味的故事（最常見的失敗原因）
- **對白太直白**：角色直接說出自己的感受/想法，缺乏潛文本
- **鋪陳太明顯**：觀眾早就猜到後面的「反轉」，失去驚喜
- **角色缺乏兩難**：角色總是有明顯的正確選項，沒有真正的掙扎

## Key Takeaways

1. **故事失敗的主因 = 忽略對立原則** — 對立愈強，故事愈精彩
2. 鋪陳必須像埋地雷：觀眾不知道它在哪裡，但爆炸時必須震懾人心
3. 角色塑造的終極考驗：「給他一個兩難選擇，看他怎麼選」
4. 潛文本是對白的靈魂 — 角色說的話和真正的意思之間的差距就是戲劇
5. 寫作是「從左腦到右腦」的過程：先學會規則，再忘掉規則，讓手自動寫
6. 「他不太確定該怎麼界定將思考轉化為文字的動作……到底天賦的來源是什麼？」
