## Core Frameworks & Mental Models

### 1. 原理 > 規則 (Principle over Rule)

麥基開宗明義區分：**規則告訴你「必須這麼做」，原理告訴你「經過時間考驗，這麼做確實行得通」**。寫好故事應遵循打造這門藝術的原理，而不是模仿寫得好的劇本。心急的作者墨守成規，離經叛道的作者衝撞規則，只有藝術家真正精確掌握形式。

**Use this when**: 面對「該不該這樣寫」的困惑 → 回到原理，不是找範本。

### 2. 原型 > 刻板 (Archetype over Stereotype)

原型故事發掘普世皆同的人生經驗，以特定文化的獨特表現方式包裝。刻板老套的故事則因內容和形式的匱乏而顯得蹩腳。原型故事能在不同文化圈中傳播 — 如同《巧克力情人》中的母女衝突，每個家庭都能理解，但細節前所未見。

**Use this when**: 擔心故事太冷門或太小眾 → 問自己：衝突夠不夠原型？細節夠不夠獨特？

### 3. 故事是生活的隱喻 (Story as Metaphor for Life)

對事件的選擇與安排，是創作者對現實世界的高明隱喻。揭開角色塑造與場景安排的表相，故事結構顯露的是創作者個人的宇宙觀。好的故事不是對現實的逃避，而是承載我們去追尋現實的工具。

**Use this when**: 思考故事的主題深度 → 你的結構本身就在表達你對世界的理解。

### 4. 對立原則 (The Principle of Antagonism) — 故事設計最重要的準則

> 「主角和主角的故事只有在對立力量迫使下，才能在理智面引人入勝，在感情面扣人心弦。」

對立力量不是指某個具體的反派，而是**對抗主角意志及欲望的所有力量之總和**。人性本就保守，我們絕不做不必要的事。因此，與主角作對的對立力量愈強大、愈複雜，角色和故事的呈現一定愈完整。

**Use this when**: 故事平淡、主角不夠立體 → 增強對立力量的層次（內在衝突 + 個人衝突 + 體制衝突 + 環境衝突）。

### 5. 觸發事件 (The Inciting Incident) — 寫作難度第二高的場景

觸發事件必須徹底顛覆主角生活裡所有的平衡力量，喚起主角期盼重新建立平衡的欲望。最恰當的時機：**觀眾對角色的了解夠多、夠深，足以作出完整的回應時**。提早一個場景不行，延後一個場景也不行。

設計問題：**「我的主角可能遇到的最糟的事是什麼？如何才能讓它最後轉化為主角遇到的最好的事？」**（反之亦然）

**Use this when**: 開場不知道從哪開始 → 先找到那個「徹底顛覆平衡」的事件，再往前倒推最少必要的鋪陳。

### 6. 場景設計五要素

每個場景必須包含：
- **轉捩點** (Turning Point) — 價值從正轉負或從負轉正
- **鋪陳/回饋結果** (Setup/Payoff) — 資訊的遞送時機
- **情緒動態** (Emotional Dynamics) — 情緒如何在場景中流轉
- **節拍** (Beat) — 角色不斷改變的行為，形塑場景的內在生命
- **選擇** (Choice) — 壓力下的選擇揭示人物真相

**Use this when**: 場景寫完覺得平淡 → 逐一檢查五要素是否到位，特別是「轉捩點」和「壓力下的選擇」。

### 7. 鴻溝原理 (The Gap) — 故事的心跳

期望 vs 結果之間的落差，是故事動力的來源。角色採取行動時，期望世界作出某種反應，但世界回應了截然不同的東西 — 這個鴻溝迫使角色調整行動，故事由此推進。

**Use this when**: 故事停滯不前 → 讓角色的行動產生意料之外的結果，迫使角色（和觀眾）重新評估。

### 8. 結構光譜：三種故事設計

麥基提出三種故事結構形式，構成一條光譜：
- **大情節/原型情節** (Archplot) — 經典設計，因果關係清晰，封閉式結局，單一主動主角
- **小情節** (Miniplot) — 簡約設計，開放式結局，內在衝突，被動主角
- **反情節** (Antiplot) — 反結構，巧合取代因果，非線性時間，破碎現實

**Use this when**: 決定短劇的結構風格 → 絕大多數商業短劇應選大情節（經典設計），除非故意實驗。

### 9. 人物弧光 = 壓力下的選擇

人物真相只能通過**壓力下的選擇**來揭示。在低壓力下說「我是好人」沒有意義；真正揭示性格的，是在兩難困境中，角色選擇了A而放棄了B的那一刻。

不自覺的欲望 vs 自覺的欲望：最立體的角色往往有一個自覺的目標（我要贏得比賽）和一個不自覺的真正需求（我需要被父親認可）。

**Use this when**: 角色感覺扁平 → 設計一個「兩難選擇」場景，讓角色在壓力下暴露真實性格。

### 10. 高潮 = 意義的終極體現

最後一幕的高潮是創作難度最高的場景。它是故事敘述過程的靈魂，如果失敗，整個故事也跟著失敗。高潮必須是**不可逆的變化** — 價值從正到負或從負到正的終極轉折。結局之後需要一個「衝突解除場景」作為緩衝，讓觀眾喘口氣。

**Use this when**: 規劃結局 → 高潮不是「事情結束了」，而是「世界的某種秩序被永久改變了」。
